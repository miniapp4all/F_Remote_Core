EN: F_remote (PC Remote Hub) is a lightweight, all-in-one remote control and system management utility for PC. It seamlessly empowers users to control system settings via mobile/web QR code, manage Sunshine game streaming servers, quick-launch apps, and execute power commands effortlessly.
